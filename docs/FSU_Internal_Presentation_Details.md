## System Architecture Summary

### Five Main Modules

1. **Administrator Module**
   - User and role management
   - System configuration
   - Access control
   - Status: To Followed Requirements

2. **Collection Module**
   - Transaction entry
   - Multiple account types (General Fund, Overpayment, etc.)
   - Report generation (Daily, Monthly, Date-range)
   - File upload and management
   - Status: Wireframe in progress

3. **Pay & Allowances Module**
   - Payslip management
   - Computation logic (salary minus days absent)
   - PDF storage
   - Status variants: PAYSLIP, READMITTED, TURNBACK
   - To Follow Computation requirements

4. **Remittance Module**
   - File upload for remittances
   - Categories: PAG-IBIG, PHILHEALTH
   - Date filtering
   - Ascending order sorting
   - Status: Wireframe complete, next to finalize

5. **Disbursement Module**
   - Budget allocation
   - Categories: Personnel Services, MOOE, Capital Outlay, Trust Receipt, Modified Disbursement System
   - Layout documented

### Access Control Model

**Access Levels**:
- **ALL Access**: Full system access
- **ADMINISTRATOR**: Administrative functions
- **CO-ADMIN**: Co-administrator functions
- **VIEWER**: Read-only access

**Role-Based Restrictions**: Users see only modules relevant to their role
